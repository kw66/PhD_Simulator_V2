# 自动游玩与教学录像审查

这是策略开发工具，当前重点是大多数的基础毕业路线，尚未通过全角色验证。
不修改游戏规则，不读取未来随机结果，不向公共留言板发消息。

## 使用

```powershell
node scripts/autoplay/run.mjs normal phd-10 292011,292028 artifacts/new-strategy-batch
node scripts/autoplay/audit.mjs artifacts/new-strategy-batch/normal-phd-10-292011.phdreplay.json
node scripts/autoplay/check.mjs
node scripts/autoplay/check-pipeline.mjs
```

路线可选 `phd-0`、`phd-10`、`master-10`。每批使用新的输出目录，保留失败结果。
输出包含原始录像、逐动作理由与资源变化、结局、独立重放教学检查，以及源码快照和摘要。
默认沿用现有录像的天赋分配，不代表最优构筑。`AUTOPLAY_TALENTS` 可传入分配 JSON；
`AUTOPLAY_CONFIG` 可覆盖策略参数，`AUTOPLAY_PLANNER` 可指向冻结策略进行对照，
`AUTOPLAY_PROGRESS=1` 输出月度进度。

发布使用 `node scripts/publish-official-replays.mjs <selection.json>`。
输入为录像路径数组；全部通过合法性、干净开局、天赋与教学质量检查后才替换公开录像。

## 策略

- 以稳定毕业为主，0点优先保转博与盲审；10点在安全预算内发展属性、实验室和会场机会。
  20点以后再补机制覆盖路线，本次不发布。
- 阅读积累加成后开稿，预算包含整篇论文、恢复月份、模型激活、实验费用、季节损耗、
  衰减和审稿期限。已有可行方案及时开工，避免反复等下月便宜方案而拖过截止期。
- 按具体月份执行科研批次，不提前购买下月才使用的模型。已有导师协作写作分时仍可
  改进个人写作；完整稿也会比较单项改进，已有模型不重复收费。
- 消费服务于可执行目标：完整论文预算、医疗与生活、确能回本的装备。
  不为笼统现金目标放弃本月可完成的论文；咖啡必须有恢复及推进收益。
- 导师好感过低时保护关系，转博前保留科研窗口；博士阶段兼顾社交成长和实验室项目。
  项目按完成距离、SAN与实际帮助判断，避免为展示机制而无条件点击。
- 参会结合差旅与稿件预算，按自然机会争取企业联系、实习、联培和恋人。
  实习按公开最坏月度SAN消耗预留六个月预算，不读取隐藏待遇，也不强求一局凑齐机会。
- 后期比较会议录用概率、举办时间及期刊版面费。期刊达到实际录用线再送审并确认发表；
  只达到送审线不等于能录用。多月持续改进的期刊路线尚未实现。

公开评审分布用于估计录用率，不读取本局未来随机状态。当前将科研期望分用于
录用率估算，仍可能乐观；概率不是保证，拒稿恢复与转博截止期仍是短板。

## 质量与验证口径

合法回放和毕业只是必要条件。独立重放检查闲置付费模型、无恢复咖啡、反复低收益科研、
低概率投稿、首稿长期拖延、已知次月负资源仍跨月等问题。另记录逐月三属性及上限、
资金、实际参会、合作项目和机会链。人工再审查阶段目标、消费用途与毕业准备。
结局金币必须结合逐月收入与支出判断，不能全部算作前期闲置。

开发种子用于调参，新种子只计冻结后首次运行。成功示范不能当稳定通关率；
策略失误不能用来判断游戏或诅咒不可通关。失败、实验源码与未采用方案保留在本地
`artifacts/strategy-repair-*`，不将大量原始日志加入站点仓库。
