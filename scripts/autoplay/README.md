# 自动游玩与教学录像审查

当前是策略开发工具，尚未通过全角色验证，不能用失败局推断游戏或诅咒不可通关。
不修改游戏规则，不读取未来随机结果，不向公共留言板发消息。

```powershell
node scripts/autoplay/run.mjs normal phd-10 1097218,271101,271118 artifacts/strategy-batch-name
node scripts/autoplay/audit.mjs artifacts/strategy-batch-name/normal-phd-10-1097218.phdreplay.json
node scripts/autoplay/check.mjs
```

输出包含原始录像、逐操作理由和资源变化、完整结局、教学质量检查。
每次迭代使用新的输出目录，失败结果同样保留。默认借用已有官方录像的天赋分配，
这不表示该分配最优，也不表示策略已适配这个角色。诅咒与尚无录像的路线尚未接入。

## 已实现

- 阶段目标、转博截止期、按月季节成本及次月资源预告。
- 阅读加成、AI 的公开期望收益、完整论文的现金/SAN/衰减和审稿时间预算。
- 草稿与审稿期间损耗分开统计：会议审稿分已冻结，不能把审稿期间衰减当作本次投稿损失。
- 对三位审稿人的公开分布积分估算录用率；概率不是保证，未读取本局随机游标。
- 消费用途、批次执行、疾病处理、毕业盲审保证分检查。
- 独立重放质量审查，发布脚本先审查全部候选，失败时不改公开录像。

## 验收口径

合法回放、毕业仅是必要条件。自动检查拒绝未使用的付费科研 AI、无恢复咖啡、
反复低收益科研、低录用概率投稿、首稿长期拖延，以及明知次月资源为负仍跨月。
贪求等消费天赋须结合真实属性收益判断，不能简单把所有消费计为浪费。
还必须人工检查角色天赋利用、每阶段目标与消费性价比，并在未参与调参的新种子上验证。

当前普适策略仍会错过普通角色的转博期限；怠惰需要休息加成的专用路线。
不得把少数成功种子写成全角色已修好，不得为通过检查而修改游戏机制。
