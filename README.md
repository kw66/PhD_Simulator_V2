# 研究生模拟器v2.0

《研究生模拟器v2.0》是一款按月推进的研究生生活模拟游戏。从入学到毕业，你需要安排有限的行动与 SAN，在科研、实验室经费、人际关系和日常生活之间做取舍。

你可以想 idea、做实验、写论文并投稿，也要面对导师交办的项目、同学的合作请求和不断变化的校园事件。论文能否发表、关系能否维系，以及最后是毕业、延毕还是提前离开，都取决于这一路的选择。

## 相比 V1

- 🧭 **生涯流程重做**：从入学选导师、硕士阶段决定是否转博，到毕业学年的论文与求职准备，经历会随月份推进。事件分幕呈现起因、选择和结果，时间轴可以回看走过的路。
- 🔬 **论文不再只是玩家的进度条**：想 idea、做实验、写作、投稿、审稿、发表和引用连成一条科研流程；草稿会随时间衰减，会议和期刊有各自的结果与开支。同学也会独立写论文、投稿，与你互相协作。
- 🧪 **实验室有自己的运转方式**：导师、玩家和同学共同推进横向、纵向项目。科研经费承担工资、实验和论文费用，项目结项又带来经费、科研积累或劳务收入，花钱与做研究因此联系在一起。
- 🤝 **人际关系会随时间变化**：同学有自己的科研能力、默契、学年和毕业去向；恋人有不同的相处路线。你的科研与社交能力也会影响合作、事件选择和学年末的实验室传承。
- 🌱 **角色天赋转向分支成长**：V1 的固定角色特性和转博觉醒，在 V2 中改为按角色设计的天赋树，展示节点前置、等级和天赋点需求。完成一局可积累角色经验；天赋树目前仅供预览，尚未开放加点和局内效果。
- 🎨 **界面与角色展示更新**：角色图鉴、科研工作站、人际卡片、效果和事件时间轴重新整理，让论文状态、行动成本与结果更容易追踪。

V2 仍在开发中：成就系统目前以预览为主；本局暂不支持存档，刷新页面会重新开始，也不兼容 V1 存档。
