# 研究生模拟器v2.0

一款按月推进的研究生生活模拟游戏。安排科研与日常，在论文、实验室、人际关系和 SAN 之间做选择，走向不同结局。

## 相比 V1

- 🧭 **生涯更连贯**：入学、转博、毕业与结局串成完整流程，事件以多幕展开，选择和结果更清楚。
- 🔬 **科研更深入**：从想 idea、做实验、写论文到投稿、审稿和引用；同学也会独立做研究，与你合作发表。
- 🤝 **实验室更鲜活**：导师项目、科研经费、工资与生活费相互影响，同学和恋人会随时间成长。
- 🎨 **界面重新设计**：角色图鉴、事件时间轴、科研工作站和人际卡片集中呈现本局进展。

V2 仍在开发中。天赋树和成就目前以预览为主；本局暂不支持存档，也不兼容 V1 存档。
