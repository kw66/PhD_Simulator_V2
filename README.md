# 🎓 研究生模拟器 v2.0

《研究生模拟器 v2.0》是一款按月推进的研究生生活模拟游戏，现已正式上线。你从入学前联系导师开始，在有限的行动点、SAN 和金币之间安排科研与生活，经历硕士、转博、毕业和求职。

这个月是赶论文、帮实验室做项目，还是先休息恢复状态？论文、导师、同学与生活开支会相互影响，一次选择的结果也可能在几个月后才显现。

## 🧠 系统与玩法

| 系统 | 可以做些什么 |
| --- | --- |
| 📅 月度生涯 | 分配行动点，处理有期限的待办事件，安排科研、打工与休息；通过时间轴回看经历与 SAN 变化 |
| 🔬 论文研究 | 积累 idea、实验、写作与协作分数，选择会议或期刊投稿，经历审稿、修改、录用和拒稿 |
| 📈 科研成果 | 发表后积累科研分与引用，宣传代表作，争取 Best Paper、顶刊与国家奖学金 |
| 👨‍🏫 导师与项目 | 推进横向、纵向项目，争取指导和报销；实验室经费承担工资、实验与发表开支，导师也会积累科研成果、晋升职称 |
| 🤝 同学与恋人 | 同学有自己的科研、论文和学业进程，可以互助、合作、转博或离校；恋人可一起玩耍、学习与购物 |
| 🛍️ 商店与效果 | 购买设备与生活用品，订阅 AI 辅助行动；在效果栏查看永久、本月、下次及下月初的增益和代价 |
| 🌱 日常成长 | 阅读、打工、羽毛球、打牌、游戏、跑腿与参会等经历会留下积累，逐渐改变后续收益 |
| 🎲 校园事件 | 实习、联培、恋爱、学术竞争和生活插曲穿插发生，多幕事件展示经过、选择与结果 |
| 🎓 毕业与就业 | 完成毕业论文并接受盲审；在大厂、央国企、公务员、教职四条赛道积累能力，参加招聘、比较和选择 offer |
| 🏅 成就与记录 | 179 个成就覆盖毕业、科研、人际、收集、彩蛋与挑战，记录完成角色、日期和全球达成率 |
| 💾 存档与结局 | 每个角色保留独立进度，支持自动存档、续玩和月份回溯；结局汇总论文、人际、工作、经历及本局成就 |

## 🎭 18 个角色，多种成长方式

新玩家从「大多数」开始，随着成就与挑战逐步解锁其他角色。正位与逆位角色通过经验升级，开局前手动分配天赋点；诅咒与特殊角色使用各自的玩法规则。

| 类别 | 角色 | 玩法特点 |
| --- | --- | --- |
| 正位 · 6 位 | 大多数、富可敌国、院士转世、社交达人、导师子女、天选之人 | 各自拥有分支天赋树，在行动、财富、科研、人际、导师资源与属性成长之间选择路线 |
| 逆位 · 6 位 | 怠惰·大多数、贪求·富可敌国、愚钝·院士转世、嫉妒·社交达人、玩世·导师子女、空想·天选之人 | 限制与特殊优势并存，围绕不同于正位的资源使用和成长方式展开 |
| 诅咒 · 4 位 | 体弱多病、有限人生、天才迟暮、寒门负重 | 不使用天赋点，挑战逐级加强的限制；正式结算博士毕业后解锁下一难度 |
| 特殊 · 统御者 | 解锁六位正位角色后开放 | 自身普通行动点为 0，依靠带有角色标签的导师、同学与恋人构建自动协作团队，仍可使用 AI 行动 |
| 特殊 · 轮回者 | 完成 24 个不同成就后开放 | 按学年继承往世同一学年的属性、成长与人际积累，在多局之间逐步积累优势 |

正位与逆位角色从 0 级成长至 10 级，每升一级获得 2 天赋点，本局开始后配置固定。成就可提供经验、经验倍率与角色解锁；跨角色收集和高难挑战另有对应奖励。

轮回者的属性与上限分别取高，成长积累与导师资源自动继承；历史同学、恋人可在空余位置选择接回。金币、物品、论文和永久 Buff 不随轮回继承，只有正式结算的生涯才会留下下一局可用的年度记录。

## ✨ 相比 V1，主要变化

| 方面 | V2 的变化 |
| --- | --- |
| 角色培养 | 固定角色特性与觉醒改为分支天赋树、角色等级和成就解锁，并加入诅咒挑战、统御者和轮回者 |
| 事件呈现 | 多幕事件配合待办期限与历史时间轴，可以查看选择前后的变化及结果 |
| 论文流程 | 细化月份衰减、审稿人意见、PC 决策与投稿历程，会议、期刊和毕业盲审都有结果展示与统计 |
| 实验室运转 | 导师、玩家与同学共同参与项目，经费、工资、科研和人际成长相互关联 |
| 关系成长 | 同学会独立研究、投稿和推进学业，恋人有多条相处进度，关系不再只有一次性事件奖励 |
| 毕业与求职 | 毕业论文包含研究点与专家盲审；求职分为四条赛道，结合月份、能力与岗位难度进行招聘 |
| 多局进度 | 每个角色分别存档，支持月份回溯；成就、等级、历史纪录和收集进度在局外保留 |
| 界面与操作 | 科研、人际、成果、商店、天赋及效果栏重新设计，支持电脑和手机浏览器游玩 |

## 💾 存档、结算与全球统计

| 项目 | 规则 |
| --- | --- |
| 自动保存 | 每个角色保留一份最新进度及最多 70 个月份存档，无需手动保存 |
| 继续游玩 | 返回开始页面或关闭浏览器不会清空生涯，再次开始该角色即可续玩 |
| 月份回溯 | 在设置或结局中读取旧月份，之后的存档与分支经历会撤回，随机序列也随存档恢复 |
| 正式结算 | 结局点击「结算并返回」后，才确认本局经验、成就、角色纪录和轮回积累；已结算角色下次可开启新生涯 |
| 本地数据 | 存档、角色成长和收集进度保存在当前浏览器，不支持账号登录与跨设备同步；清理网站数据会丢失本地进度 |
| 全球数据 | 留言、开局与结局统计、论文及盲审统计、成就达成率接入数据库；全球成就达成率以所有开局玩家为分母 |

V2 不兼容 V1 存档。打开调试面板的局不发放经验或成就奖励，也不再提交后续全球统计。

## 🛠️ 本地运行

需要 Node.js 20.19+（20.x）或 22.12+，在仓库目录执行：

```bash
npm install
npm run dev
```

按终端提示打开本地地址即可。`npm run verify` 运行类型检查、测试与构建，`npm run build` 生成静态站点。
