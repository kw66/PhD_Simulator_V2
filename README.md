# 研究生模拟器v2.0

《研究生模拟器v2.0》是一款按月推进的研究生生活模拟游戏。你从入学前联系导师开始，在有限的行动点、SAN 和金币之间安排科研与生活，经历硕士、转博和毕业阶段。

这个月是赶论文、帮实验室做项目，还是先休息恢复状态？论文、导师、同学和生活开支会相互影响；一次选择的结果，也可能在几个月后才显现。

## 一局怎么玩

- **安排每个月**：在科研、看论文、打工和休息之间分配行动，同时处理会随时间到来的校园事件。
- **完成研究**：为论文积累 idea、实验和写作分数，选择会议或期刊投稿；发表后继续关注科研分、引用和宣传。
- **维系关系**：与导师推进项目，和同学合作，也可以经营恋爱关系。经费、工资与生活费决定实验室和个人能否继续运转。
- **走向结局**：硕士阶段可以申请转博；毕业学年还要准备毕业论文和求职。顺利毕业、延毕或提前离开，都由过程决定。
- **随时续玩**：每个角色分别保留一局进度，每月自动存档，也保存当前进度。返回首页或关闭浏览器后，可以继续原来的生涯。

## 相比 V1

### 🧭 事件与生涯更连贯

事件不再只给出一段选择和一次结算，而是依次展示事情发生、作出决定和最终结果。待办事件可以在期限内处理，时间轴记录每个月的经历；转博、毕业论文和毕业判定也接入同一条生涯流程。

### 🔬 论文有更完整的后续

草稿和会议审稿中的分数会随月份衰减，拒稿后可以根据反馈继续修改。投稿结果由不同审稿人和 PC 决定；录用后的参会、期刊版面费、引用增长和成果宣传，也各有后续选择与代价。

### 🧪 实验室不只是背景

导师、玩家和同学共同推进横向、纵向项目。科研经费承担工资、实验和论文开支，项目结项又能带来经费或劳务收入；经费紧张时，做实验、报销和同学的工作安排都会受到影响。

### 🤝 同学与恋人会自己成长

同学有独立的科研能力、论文和学业进度，会投稿、与你互助，也可能转博或离校。恋人有玩耍、学习和购物三条相处路线；科研与社交能力还会影响合作、会场交往和学年末的实验室传承。

### 🌱 角色成长改为天赋树

V1 的固定角色特性和转博觉醒，在 V2 中改为按角色设计的分支天赋树。目前已实装大多数、富可敌国、院士转世、社交达人、导师子女、天选之人及对应逆位，共 12 个角色的天赋。开局前手动分配天赋点，本局开始后配置固定，不同路线会改变资源安排、属性成长与事件收益。

角色从 0 级成长到 10 级，每升一级获得 2 天赋点。结算科研成果和成就可获得经验；毕业及角色挑战还会提升经验倍率、解锁后续角色。新玩家从大多数开始，图鉴中其余特殊、诅咒角色尚未开放。

### 🏅 成就鼓励探索不同玩法

除了毕业与论文成绩，成就也覆盖人际、商品、事件彩蛋和特殊挑战。成就会记录完成角色与日期，并展示全球达成率；部分收集目标可以跨局、跨角色推进。同一成就的重复完成可留下记录，奖励按各自规则领取，不会反复发放。

### 💾 一局可以保存和回溯

每个角色最多保留 70 个月初存档和一份最新进度，在设置中可以读取旧月份。读档会删除该分支之后的存档并撤回相应经历，随机序列也随存档恢复。结局可选择回溯，或点击「结算并重开」确认本局成果，再发放经验和成就奖励。

存档和角色成长保存在当前浏览器，暂不支持登录与跨设备同步；清理网站数据会丢失本地进度。留言和匿名全球统计接入数据库，论文、期刊与毕业盲审结果可以查看玩家统计。

### 🎨 信息更容易追踪

角色图鉴、科研工作站、人际卡片、效果栏和事件时间轴重新布局。论文状态、行动成本、关系变化与事件结果尽量在对应位置呈现，减少来回查找。

V2 持续更新中，暂不兼容 V1 存档。电脑和手机均可游玩；打开调试面板的局不参与经验、成就与后续全球统计。
