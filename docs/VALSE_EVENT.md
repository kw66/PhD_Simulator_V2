# 领域年会：VALSE

2026-10-08 更新。

- 显示名统一“领域年会”“领域年会活动”，内部事件ID暂沿用ccig，调试、回退和已审阅状态使用同一事件标识。
- VALSE（视觉与学习青年学者研讨会）免注册费；游戏只收差旅2金币，有无论文价格相同。自费扣个人金币2，报销扣科研经费2并沿用导师好感规则；可选参会余额不足时不扣款。VALSE的免注册费不适用于已录用论文的必付注册费；论文会议注册与差旅均在录用3个月后支付。
- 费用构成放在第二幕剧情，第三幕只显示金币或科研经费及实际好感变化。活动第一、二幕不再重复之前的参会结算。
- 领域年会与论文参会结果不再显示参会次数递增。内部计数保留，会议经验减费天赋保持删除。
- 剧情采用预注册、参会确认、签到凭证、特邀报告、Tutorial、Workshop和顶会顶刊海报交流等实际活动细节。海报不新增投稿录用奖励，保留既有A类论文展示条件。
- 已核实城市：2024重庆、2025珠海、2026武汉；后续未核实年份仅称“外地”，不编造举办城市。游戏仍沿用每年5月固定事件节点，属于日历简化；现实2025届为6月6—8日，并非每届固定5月。
- 结果中的费用统一写“科研经费”，与导师卡一致；说明正文仍可用“实验室经费”解释所属账户。
