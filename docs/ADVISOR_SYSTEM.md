# 导师科研与经费

本规则取代旧导师科研资源、信任度、任务条和关系条。导师好感仍是玩家属性，与本系统独立。

## 初始与横向

- 科研积累初始20，不设上限；科研经费初始10，不设上限
- 横向、纵向各有一条实验室共享进度（100），导师、同学和玩家都累加到这两条进度，没有独立的同学项目条；超出100的部分保留
- 每完成一个横向，科研经费+20、玩家劳务费+5；每完成一个纵向，科研积累增加当前值的10%（下取整），为玩家和当前每位同学各触发一次论文指导，恋人不参与
- 同学项目推进为⌊自身科研⌋+随机0～5，普通项目统一按本轮月初结算开始时的经费选择：达到20选纵向，否则选横向。同学实际做实验时经费-3，不受玩家个人显卡减免；经费不足3时改为推进共享横向，下月继续尝试科研
- 玩家可选择“做横向”或“做纵向”，不占行动点，每月限一次；横向基础消耗SAN5，纵向基础消耗SAN4，进入下月恢复；操作失败不占次数
- 实际SAN消耗为 `max(0, ceil(基础消耗 × 疾病倍率) + 人际固定修正 + 季节修正 + 恋人玩耍修正)`。人际减免含Gemini 3及后续型号，对同学、导师与恋人均生效；项目不应用事件科研任务的科研档位减免
- SAN不足时不可操作；费用、按钮与角标统一读取 `getAdvisorTaskSanCost(state, projectType)`，不使用旧关系任务奖励。上述消耗修正不作用于固定月度SAN扣除、恢复或上限变化
- 经费为0时导师跳过本月横向，下月轮到纵向；科研经费不足时，玩家实验由个人金币补足，同学实验改为推进横向

## 月度结算

导师晋升：导师职称依次为讲师、副教授、教授四/三/二/一级时，硕士每月补助为1、1.25、1.5、1.75、2、2.25金币，博士为3、3.5、4、4.5、5、5.5金币。每次将标准补助与上次保留的小数相加，发放整数部分并保留小数，1.5对应1、2、1、2。导师晋升后的下次月初起按新标准发放；转博按当前职称对应的博士标准发放，晋升和转博均保留小数余额，经费不足不停发。晋升增加补助时单独记录天赋事件。

入学9月不结算，从10月开始每次进入新月结算一次。以游戏累计月份去重，重复渲染、切页和操作不重复结算。

1. 汇总新发表论文，增加科研积累
2. 月初导师轮流推进项目：导师每月推进10；经费为0时跳过本月横向，下月推进纵向
3. 8月结算已提交的年度申请，经费一次性到账
4. 3月在本月项目推进后检查年度申请

当选院士时一次性科研经费+200。

导师卡片顶部显示姓名、职称、科研经费和在研基金。下方依次是科研积累、纵向、横向三条进度；科研积累行末显示申请目标与倒计时，已达到的档位移入悬浮提示。项目按钮与对应进度条同排。悬浮或键盘聚焦进度名称可查看主动推进和达标奖励，科研积累提示也说明玩家及同学论文按科研分去重计入。底部只保留本月活动，记录导师月初推进，手动操作不覆盖；导师、恋人和同学卡片在相同屏幕尺寸下同高。

科研经费优先抵扣实验金币；一次实验只按一次点击结算费用。先从基础3金币扣除个人显卡与实习减免（最低0），再使用科研经费，不足部分由玩家金币补足。个人显卡减免显示在永久效果，实习减免显示在本月效果；实验按钮显示自付金币，悬浮提示显示同一份结算中的经费消耗。

## 论文贡献

同学加入时建立草稿，次月首次行动推进科研。每成功科研一次，下月做一次项目，再回到科研；审稿等待期间每月做项目。月初先结算衰减和审稿结果，再兑现可用的帮助并选择行动：中稿当月开启并研究新稿，退稿当月继续修改，不受入组月份奇偶影响。

科研优先补齐idea、实验、写作，三项齐全后选择自身与协作合计分最低项，并列按idea、实验、写作顺序。实验缺钱时当月做横向，保留次月科研安排；次月重新判断最低项，若已变为idea或写作就研究该项。科研后达到当前会议参考分即投稿，优先A、其次B、C。

同学每月只执行一次科研或项目行动，按人际卡片从左到右、从上到下结算。实验使用轮到自己时的实时余额，前面的横向完成所获经费可供后面的实验使用；普通项目方向仍以月初经费为准。当月已经行动的同学不追加实验。自动互助与导师指导不占行动，也不改变科研与项目的交替安排。

玩家已发表论文（含合作成果）及当前人际栏同学的已发表论文共同计入，恋人主导的论文不计入。以论文ID永久去重，同一篇在多个列表出现只贡献一次。停止合作不扣回已贡献的分数；停止合作后，未署名为玩家合作成果的对方论文不再新增贡献。

贡献采用论文等级的固定科研分：A/B/C为4/2/1，Nature/NMI/PAMI为20/10/5。不采用录用总分、当前分或引用数，不随论文分数衰减。

发表后的作者列表固定包含导师，不要求导师曾为该论文加分。导师实际指导记录在协作者中时，发表署名也只显示一次；同学则按论文保存的实际协作者记录署名。

- 每年3月自动申请符合门槛与限项的最高新档，冻结当次科研积累快照，8月确定获批，不抽概率
- 所有档位只获得一次，取消第二项面上；获得高档后不补领低档，允许跳级
- 积累不因申请或获批扣除，职称不再要求累计到账经费
- 讲师限1项，晋升后限2项；限项时不申请，院士不占名额
- 获批即占名额，从次年1月开始执行；申请当年资助期满的项目不计限项
- 例如2024年获批青基，执行期为2025—2027年，2027年3月申请时不再占用名额
- 暂不叠加现实中优青执行期间申请杰青等特殊限制
- 项目到期仅释放名额，不失去帽子与职称

当前游戏第六年4月结束，因此第六年3月可以申请，但8月结果不会提前发放。

## 当前边界

导师卡、帮助说明、科研积累、经费、横向/纵向按钮、年度申请、获批日志、导师指导和实验经费抵扣已经接入。各级职称对应的补助按卡片与帮助页显示。

导师自动项目、同学自动项目和导师指导不写入普通游戏日志；本月活动显示在对应人际卡片底部，同学实验活动注明经费消耗。纵向项目满100时，导师分别为玩家和每位同学指导一次，各随机选择一篇可操作论文，写作协作分+10；会议审稿中的论文不接受指导，期刊修改稿可以接受。写作需要已有实验分，没有符合条件的论文时各自最多暂存一次。暂存指导在论文具备实验分、变为可修改或后续操作时自动结算，消费后不会重复发放；指导属于协作加分，不额外收取实验费。

## 导师项目事件

“导师项目”（random-4）中，导师与玩家谈话，请玩家牵头负责项目、同学配合。日常人际按钮是参与项目，事件接下项目则直接推进对应共享进度100，完成一次项目，原有进度余额保留。

- 横向：基础SAN-8，横向进度+100。由共享项目结算科研经费+20、玩家劳务费+5，事件额外导师好感+1，不重复直接发放金币
- 纵向：基础SAN-6，纵向进度+100。由共享项目结算导师科研积累+⌊当前积累×10%⌋，为玩家和每位同学各指导一次；事件额外导师好感+1、科研+1
- 事件SAN使用科研任务减免及通用消耗修正，不调用人际项目按钮的费用，也不占用人际项目的每月操作次数；好感和科研沿用事件属性抵抗与上限
- 第三幕确认才提交项目奖励和指导；预览、回看与重复确认不重复发奖。纵向指导的随机数随事件选择保存，预览刷新不重新抽取指导目标
- “拒绝承担”保留导师好感-2及抵抗；“让师弟师妹分担”保留原交接消耗与社交影响，本次不增加项目进度

“导师经费”事件仍按其原有选项结算，尚未改造为新项目进度。联培中已失去含义的“导师科研资源+2”已删除，其余效果保留。
