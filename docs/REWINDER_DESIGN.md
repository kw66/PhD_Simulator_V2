# 轮回者设计与当前开放范围

2026-10-17：轮回者已正式实装。完成24个不同成就后可开局，年度轮回、跨局继承、人际选择、存档和操作复算均已接入。

开始页和局内天赋页展示属性轮回、天赋轮回、人际轮回三个继承节点及一个特殊玩法总览，无需加点。

## 解锁

正式完成24个不同的已知成就，解锁轮回者。相同成就在不同角色完成只算一次，各角色独立毕业成就分别计数；本解锁成就不计入自身条件。只奖励角色解锁，不额外给予经验。已有合格账号加载时补齐，调试局不累计。

## 轮回规则

- 每学年最后一个月发动轮回；每学年独立保留记录，不提前使用后续学年的记录
- SAN、科研、社交、导师好感及其上限逐项取高，各项可以来自不同轮回；恢复不经过抵抗
- 玩家金币不继承，商品不继承，咖啡与自行车进度不继承
- 天赋仅继承成长进度，各项自动取高；恢复进度不补发历史奖励。装备、关系、发表天赋不直接继承
- 永久及临时Buff不继承；科研栏论文和成果栏已发表论文完全不继承
- 实习次数和联培经历可保留，正在进行的实习及临时效果不继承；联培永久Buff也不继承
- 导师不替换身份；经费、科研积累和职称取高，帽子合并去重；不重发基金、不重置项目期限
- 同学与恋人按整个位置继承：玩家先手动解除当前关系，再勾选历史人物加入空位；不覆盖在场人物，不突破人数限制，不重复加入同一个人
- 同一历史人物每局只能恢复一次，避免解除后重复恢复旧进度套取奖励；回溯会同时恢复已用人物记录
- 历史人物恢复身份、属性、上限、成长进度、奖励轮次，排除现金、论文及不继承的Buff；不重发旧的入组、恋爱或协作奖励
- 系统自动记录，展示本世与历史的详细对比；正式结算后记录供下一世使用，读档撤回放弃分支，调试局排除

正常学年8月结束时先完成年度成长，再触发轮回；毕业学年6月则在离校判定前触发。确认后自动进入下月或结局，不重复结算年度成长。

本局开局冻结账号的往世档案；各年记录与人物选择随月度存档保存，回溯撤销未来分支。只有“结算并返回”将本世已完成学年的记录合并至账号，调试局或操作复算失败局不写入。账号写入失败时保留结局及本局存档，可重试；旧角色存档无需清空。

轮回档案保存在现有本地账号信封内，无需新增数据库表；全球统计继续使用现有轮回者角色及成就资格。新增操作使用 r4 规则复算，旧操作保留原规则，以免统御者修复误伤旧局。
