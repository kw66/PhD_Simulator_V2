# 论文协作分

论文每项分数由自身分和协作分组成。`idea`、`experiment`、`writing` 保持为合计分，供投稿、审稿、期刊评分、事件条件和成果结算共用；`collaborationScores` 保存各项协作分，自身分为合计分减去协作分。旧论文缺少该字段时，已有分数全部视为自身分。

## 更新规则

- 本人的科研操作仍按原科研、装备、AI 与 Buff 顺序生成分数，但只与自身分比较：`新自身分 = max(旧自身分 + 1, 本次生成分)`；协作分保持不变。额外操作依次使用上一遍的自身分。
- 同学帮助通过 `addPaperCollaboration` 累加到指定论文的协作分，也可以由事件效果 `paperCollaborations` 结算。同一人、多个人的有效帮助都持续累加，没有玩法上的分数上限。
- `collaborators` 只保存去重的人物 ID 与姓名，不保存个人贡献数值。只有实际增加分数才登记名字；相同姓名、不同 ID 仍是不同的人。历史名字不依赖当前人际栏。
- 主动协助只作用于一作草稿或期刊修改稿；会议审稿中和已发表论文不接受新协助。没有选定目标、没有有效加分时不新增协作者。
- 三幕事件在最后确认时按论文当前状态结算协助与清零；中途投稿或丢弃不会误加分，同月重建论文也不会继承旧事件的目标。
- 装备、AI 润色、审稿反馈增加自身分。协作分不参与玩家科研操作的倍率计算。

## 衰减和论文事件

发表前仍使用现有衰减：每项合计分大于 1 时，扣除 `min(合计分 - 1, max(1, floor(合计分 × 热度 × 10%)))`。期刊修改期不衰减。

先计算整项扣分，再按自身与协作占比分摊。两部分先分配向下取整的扣分，剩余扣分归小数余量较大的一方；并列时归自身。两部分相加始终等于衰减后的合计分。最低 1 分只针对整项，不对自身或协作分别保底。

被抢发 idea、新 SOTA 等整项倍率调整先按原规则算出新的合计分，再按相同比例分摊增减；不会再次调整投稿快照。数据丢失清零草稿时，两部分同步清零。协作者名单保留。

## 投稿和成果

- 会议审稿冻结三项合计分；当前自身和协作分继续一起衰减。拒稿后保留当前两部分，再增加自身的审稿反馈分；会议撤稿保留当前分数。
- 期刊初始分仍按送审时三项合计分的几何均值计算，送审后的净新增分数进入修改进度。期刊撤稿沿用恢复投稿分的规则，并同时恢复当时的协作分，防止把协作分误算成自身分。
- 停止合作或分手不删除论文已获协作分及协作者名单。论文发表后沿用现有有效分、引用和衰减规则。
- 新论文的作者列表采用真实协作者；没有协作者时不从当前人际栏随机补人。旧论文缺少名单时兼容原来的显示方式。

## 界面与范围

科研卡片前三列上行为各项合计分（含协作），下行为自身分（合计减去协作），包括0分也直接显示数值，不加正号。最右侧总分跨两行，仅显示三项合计。期刊修改卡沿用这两行，同时保留顶部期刊修改分；底层计分规则不变。

卡片顶部状态栏先展示玩家本人，再按保存顺序展示协作者圆圈头像，不显示“协作者”文字或底部占位行。颜色由人物ID的稳定哈希生成色相，支持超过六位历史协作者，圈内为姓氏或首字母（英文大写），悬浮展示完整姓名，玩家附带“（你）”标记。重名但ID不同的人保留各自头像；停止合作或分手后仍显示论文保存的名单。过滤空白协作者姓名，其余姓名及悬浮提示均转义，不展示个人贡献分；没有协作者时仍显示玩家头像。玩家仅在界面加入，不写入论文的协作者记录。

空白、未解锁及有论文的卡片共用144px基础高度，内容较多时自然增高；分数紧接题目与标签，不再用自动上边距撑开空白。空白和未解锁卡片不显示分数行或头像。科研提示明确“上行是包含协作的合计分，下行是自身分”，科研操作只更新自身，同学帮助持续累加。

本次确定并实现分数结算和展示。人际帮助的触发条件、次数、回助进度、SAN 消耗及同学自己的论文循环仍待后续讨论，未新增可免费领取协作分的正式按钮。
