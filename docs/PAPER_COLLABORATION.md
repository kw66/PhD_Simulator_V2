# 科研协作分

2026-09-18：新生成的师兄/师姐科研为6～9，同门3～6，师弟/师妹0～3，初始默契统一为1。沿用生成种子取余规则，各档科研为基值加种子对4取余；事件额外初始默契留待事件改造时设计。每位同学每月可进行一次“科研协作”，三类基础 SAN 消耗依次为4、3、2，仍经过现有季节、疾病和人际减耗修正。主动推进 `floor(玩家科研)+随机整数0～5`；加入次月起，每月结算时推进同学默契值，不再乘0.5。移除同学的关系积累条、免费推进及手动领取入口。

协作进度每满100，扣除100并保留余量，双方分别获得一次自动论文帮助，各最多保留一次。满条时记录帮助方的科研分数，待用机会不被后续完成覆盖；双方独立触发，无需同时拥有可修改论文，也不受待办事件阻塞。0分帮助不增加论文分或作者记录，结算后清除，避免占住后续机会。

玩家帮同学：提升同学当前稿件合计分最低的一项，并列按idea、实验、写作。同学帮玩家：师兄/师姐随机选择一篇可操作稿件提升idea，师弟/师妹随机选择一篇可操作稿件提升实验，同门从可操作的论文分项中随机选一项；每次只改一篇的一项。想idea无前置，实验需要idea分，写作需要实验分；没有符合对应分项条件的稿件时保留帮助。加分等于已记录的帮助方科研，不再叠加装备或Buff倍率。月初先结算分数衰减和审稿结果，再结算协作与自动帮助，最后安排同学本月行动；拒稿变为可修改或接收后新开稿件时，也会尝试兑现待用帮助。

导师指导：为玩家及每位同学分别随机选择一篇可操作稿件，写作协作分+10；尚无实验分时暂存指导。恋人学习的论文奖励：从玩家全部可操作分项中选择合计分最低的一项，并列随机选择，加分为奖励触发时的恋人科研。两者均只提升一篇的一项，无合适目标时各自最多暂存一次。

一次帮助补齐其他待用帮助的前置条件时，同次操作继续兑现，直到没有可用目标或待用机会。例如师兄补上idea后，已暂存的师弟实验帮助立即生效，再触发已暂存的导师写作指导；无需额外点击，已消费的机会不会重复发放。

论文每项分数由自身分和协作分组成。`idea`、`experiment`、`writing` 保持为合计分，供投稿、审稿、期刊评分、事件条件和成果结算共用；`collaborationScores` 保存各项协作分，自身分为合计分减去协作分。旧论文缺少该字段时，已有分数全部视为自身分。

## 更新规则

- 本人的科研操作仍按原科研、装备、AI 与 Buff 顺序生成分数，但只与自身分比较：`新自身分 = max(旧自身分 + 1, 本次生成分)`；协作分保持不变。额外操作依次使用上一遍的自身分。
- 同学帮助通过 `addPaperCollaboration` 累加到指定论文的协作分，也可以由事件效果 `paperCollaborations` 结算。同一人、多个人的有效帮助都持续累加，没有玩法上的分数上限。
- `collaborators` 只保存去重的人物 ID 与姓名，不保存个人贡献数值。只有实际增加分数才登记名字；相同姓名、不同 ID 仍是不同的人。历史名字不依赖当前人际栏。
- 主动协助只作用于一作草稿或期刊修改稿；会议审稿中和已发表论文不接受新协助。没有选定目标、没有有效加分时不新增协作者。
- 三幕事件在最后确认时按论文当前状态结算协助与清零；中途投稿或丢弃不会误加分，同月重建论文也不会继承旧事件的目标。
- 装备、AI 润色、审稿反馈增加自身分。协作分不参与玩家科研操作的倍率计算。

## 衰减和论文事件

发表前仍使用现有衰减：每项合计分大于 1 时，扣除 `min(合计分 - 1, max(1, floor(合计分 × 热度 × 10%)))`。期刊修改期不衰减。

先计算整项扣分，再按自身与协作占比分摊。两部分先分配向下取整的扣分，剩余扣分归小数余量较大的一方；并列时归自身。两部分相加始终等于衰减后的合计分。最低 1 分只针对整项，不对自身或协作分别保底。

被抢发 idea、新 SOTA 等整项倍率调整先按原规则算出新的合计分，再按相同比例分摊增减；不会再次调整投稿快照。数据丢失清零草稿时，两部分同步清零。协作者名单保留。

## 同学成长（2026-09-20）

天赋→关系依次为导师关系、实验室传承、论文合作、恋人、大牛联培、企业实习。前三张默认激活，恋人位于第四；恋人、大牛联培、企业实习的卡片统一展示“待定”，本次不调整其既有事件与效果。导师天赋效果待定，原有导师科研积累与经费系统不变。卡片仅说明规则，不列同学名单或完成记录；不再为每位同学单独生成天赋卡片。旧“实验室互帮互助”的师兄/师弟组合条件、团队人数科研操作加分及卡片已删除。

- **实验室传承**：每位当前合作同学每认识12个月，科研增加 `floor(n / 2)`，科研上限20。n为科研比自己高的人数；比较玩家和其他当前合作同学，严格大于才计数，导师视为1人，恋人不计。所有同学使用成长前的同一组数值比较，不受名单顺序影响。按各自认识月份结算，不在全局学年末统一结算，同月只结算一次。
- **已移除同学成长**：删除卡片及首次C/B/A发表增加科研的机制和领取记录字段，同学发表不再额外增加科研。
- 月度顺序：先结算年度成长，再推进协作和同学科研。既有待兑现帮助保留原科研快照。
- **论文合作**：每篇玩家与当前合作同学共同发表的论文，双方的默契+1，上限20；双方任一人一作均可，以实际协作者ID判定。每位同学按论文ID去重，一篇论文在不同列表出现或反复结算不会重复加默契；达到上限也记录为已结算。会议、期刊均在接收后结算；投稿中、拒稿、单独发表均不触发。停止合作后不再给离开的同学结算，新同学不会继承其他ID的记录。
- 实验室传承只增加同学科研，不增加玩家科研或默契。协作条满不增加默契，默契在每篇共同发表时增长。互助是否增加玩家科研仍待讨论，当前不增加。

## 投稿和成果

- 会议审稿冻结三项合计分；当前自身和协作分继续一起衰减。拒稿后保留当前两部分，再增加自身的审稿反馈分；会议撤稿保留当前分数。
- 期刊送审分、修改分和录用分均直接取当前idea、实验、写作的总和，包含自身与协作分；不再使用几何均值或“投稿分+净新增”的单独算法。三项都有分且总分达到送审线才可投稿，录用门槛不变。期刊撤稿沿用恢复投稿分的规则，并同时恢复当时的协作分，防止把协作分误算成自身分。
- 停止合作或分手不删除论文已获协作分及协作者名单。论文发表后沿用现有有效分、引用和衰减规则。
- 新论文的作者列表采用真实协作者；没有协作者时不从当前人际栏随机补人。旧论文缺少名单时兼容原来的显示方式。

## 同学月度流程

- 加入时立即建立草稿，次月首次科研。每成功科研一次，下月做一次共享项目，再回到科研；审稿等待期间每月做项目。分数衰减、引用、协作和待用帮助仍按月结算。
- 审稿结果在本月行动前结算：录用当月建立新稿并想idea，拒稿当月修改合计分最低项。科研优先按idea、实验、写作补齐缺项，三项齐全后比较自身分与协作分的合计，选择最低项，并列按idea、实验、写作顺序。科研后达到当前会议参考分即投稿，优先A，其次B、C。
- 轮到做实验时，科研经费不足3则当月改做共享横向，保留科研安排，下月重试。每次重试都按当前三项合计分重新选项，若最低项已变为idea或写作，就研究该项；成功科研后才安排下月做项目。
- 普通项目统一按本轮月初结算开始时的经费快照选择：经费达到20做纵向，否则做横向；实验经费不足时固定做横向。共享进度、项目奖励和导师指导见[导师科研与经费](ADVISOR_SYSTEM.md)。
- 同学按人际卡片从左到右、从上到下依次行动，每人每月只做一次科研或项目。实际实验每次扣除3科研经费，按轮到该同学时的实时余额判断；前面的横向完成所获经费可供后面的实验使用，已经行动的同学当月不再补做实验。
- 自动互助和导师指导不占月度行动，也不改变科研与项目的交替安排。

## 界面与范围

科研卡片前三列上行为各项自身分（合计减去协作），下行为协作分，包括0分也直接显示数值，不加正号。最右侧总分跨两行，等于六格分数之和。移除分数格的悬浮提示，含义统一放在科研小提示中。期刊修改卡沿用这两行，同时保留顶部期刊修改分；底层计分规则不变。

卡片顶部状态栏先展示玩家本人，再按保存顺序展示协作者圆圈头像，不显示“协作者”文字或底部占位行。颜色由人物ID的稳定哈希生成色相，支持超过六位历史协作者，圈内为姓氏或首字母（英文大写），悬浮展示完整姓名，玩家附带“（你）”标记。重名但ID不同的人保留各自头像；停止合作或分手后仍显示论文保存的名单。过滤空白协作者姓名，其余姓名及悬浮提示均转义，不展示个人贡献分；没有协作者时仍显示玩家头像。玩家仅在界面加入，不写入论文的协作者记录。

空白、未解锁及有论文的科研卡片共用144px基础高度，内容较多时自然增高；分数紧接题目与标签，不再用自动上边距撑开空白。空白和未解锁卡片不显示分数行或头像。科研提示明确“上行自身、下行协作、总分为六格之和”，科研操作只更新自身，同学帮助持续累加。

同学自己的论文循环与双向协作已接入。协作条满后自动选择论文和分项，玩家实际协助时写入同学论文的协作者记录；该论文录用后计入玩家非一作成果。事件侧的旧奖励与联动仍有待改项，见 [事件与同学论文联动待办](EVENT_SOCIAL_LINKAGE_TODO.md)。

人际卡片沿用科研卡片的边框、头部分隔线、字体和字号。基础高度176px，窄屏适当增加，导师、恋人、同学及未解锁卡片保持同高。顶部左侧显示身份、姓名、科研、默契，右侧显示认识月数与停止合作；题目后的方向、热度标签与题目紧邻，分数行在其下，审稿时替换为会议等级、名称、剩余月数和当前总分。

协作行依次为名称、进度条、数值、按钮。悬浮或聚焦名称显示本次主动推进和条满双向帮助；每月结算时对象的推进记录在本月活动栏。具体加分仍以满条时记录为准。认识月数提示实验室传承的公式和当前预计提升，论文区域提示共同中稿默契+1及署名条件。底部保留本月活动，移除重复的条满说明。使用后协作按钮禁用且不再显示消耗；审稿期间也能推进协作，但会议论文仍须等待结果才能接受加分。相关规则同步显示在右侧帮助中。

每个同学创建 ID 时生成并保存 `researchTopic`（方向与热度），其后所有新稿沿用，题目在该方向内生成。已有未带方向字段的同学优先继承正在研究的论文方向。停止合作位于卡片右上角，进行中的待办事件不再阻止结束关系，既有论文贡献和待办仍保留。

科研协作不要求有论文，不受零分、投稿审稿或待办事件阻塞影响；仍检查游戏阶段与正式入学限制，每人每月一次且需足够 SAN。自动帮助只要求受助方有可修改论文，另一方正在投稿不会阻止这次加分。
