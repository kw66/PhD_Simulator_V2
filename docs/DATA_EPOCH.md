# 数据重置边界

本轮进度与统计从北京时间 **2026-10-16 13:25:29**（`2026-10-16T05:25:29.000Z`）重新开始。统一常量位于 `src/core/v2-data-epoch.ts`。

- 新账号包络使用 `phd_simulator_v2_account_v2`，必须带当前 `epoch` 和不早于起点的有效 `savedAt`
- 不读取旧账号包络，也不从历史独立键导入经验、解锁、天赋分配、成就、成就奖励、收集进度或历史成绩
- 旧已结算标记及待上传 outbox 随旧账号包络失效，不能在升级后重新交付或领奖
- 各独立记录同样带 `epoch` 和 `savedAt`：经验键升为 v3、成就键升为 v3、天赋键升为 v3、角色历史键升为 v2；即使旧内容被放入新键，缺少纪元及日期也不会加载
- 每条成就达成日期还须不早于起点；早于起点的达成记录不能恢复
- 局内存档、月度操作复核和在线统计共用同一个重置边界。旧局不能作为新纪元进度继续结算

旧浏览器记录可以留在原键中，但不参与新游戏。此项目没有手动导入备份入口；以后新增导入功能也必须复用纪元与日期检查，不能绕开包络直接导入旧进度。

浏览器日期和纪元标记用于隔离旧版本数据，不等于服务端防作弊证明；本地存储和本地时钟仍由玩家设备控制。
