# 天赋触发记录

天赋触发直接写入事件页当前月份日志和已完成事件历史，不进入待办队列、不阻塞下一月，也不需要重复确认。点击日志可回看触发时的对象、原因、效果和必要的关联论文，之后属性变化不会改写历史。

- 发表天赋每项独立记录，保留原有同时达成多项时的奖励合计和上限结算方式，记录实际获得的属性变化；达到上限时说明未增加，不显示虚假的完整收益。论文结果仅保留录用决定、科研分和审稿影响，不预览或嵌入天赋奖励。
- 实验室传承逐人记录姓名、认识月份及科研前后值；周期已到但未增长时说明原因。论文合作逐人记录默契前后值及本次共同发表的论文，同篇按原有论文ID记录去重。
- 阅读积累、兼职熟练度、会议经验、羽毛球水平、牌局策略、骑行积累、高级咖啡机、整装待发和AI协作的成长/激活节点进入同一记录系统。连续生效的月度收益仍保留原有月初结算来源。
- 成长和装备记录由动作前后状态比较产生，只记录实际跨越的节点，不改变奖励规则。嵌套自动事件结算检查新增历史避免重复；纯调试属性变更不生成这些观察记录。角色尚未实际执行的天赋不根据说明文本伪造奖励。
- `v2-talent-history.ts` 负责只读历史格式与幂等写入，使用稳定ID，不额外消耗游戏随机数；`v2-talent-transitions.ts` 负责通用动作节点，发表与同学成长在各自实际结算点记录。
