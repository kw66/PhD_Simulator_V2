# 审稿系统 V2

## 投稿与时效

- 投稿时冻结 `idea`、实验、写作三项分数，审稿人只使用这份快照
- 普通会议审稿期为 4 个月
- 审稿期间论文的当前三项分数仍按选题热度自然衰减
- 拒稿后回到草稿时保留已经衰减后的当前分数，并叠加审稿人的改进建议

## 审稿人

当前共有八类审稿人。第一年基础概率按固定顺序为：新颖性 10%、实验 10%、普通 30%、LLM 10%、资深 10%、心软 10%、严格 10%、恶意 10%。

从第二年开始，每过一年按同一顺序增加：`+1%、+1%、-5%、+4%、-1%、-1%、+1%、+0%`。概率先逐项限制为不低于 0，再归一化为总和 100%。

- 新颖性审稿人：`idea ×2 + 实验 ×0.5 + 写作 ×0.5`；拒稿后论文 `idea +5`
- 实验审稿人：`idea ×0.5 + 实验 ×2 + 写作 ×0.5`；拒稿后论文 `实验 +5`
- 普通审稿人：三项随机权重，总权重为 3；拒稿后论文 `idea +2、实验 +2、写作 +2`
- LLM 审稿人：三项随机权重，总权重为 3，权重波动显著大于普通审稿人；无额外改进
- 资深审稿人：只看最高两项，各乘 `1.5`；拒稿后论文 `idea +10`
- 心软审稿人：只看最高一项，乘 `3`；确认结果时 `SAN +1`
- 严格审稿人：只看最低两项，各乘 `1.5`；拒稿后论文的最低两项分别 `+3`
- 恶意审稿人：只看最低一项，乘 `3`，重点挑 SOTA、局限性和新颖性；确认结果时 `SAN -2`

新颖性、实验、普通和资深审稿人的基础拒稿线/接收线沿用普通审稿人；心软审稿人沿用原心软线；LLM 沿用原 LLM 线；严格沿用原严格短板线；恶意沿用原极端短板线。

普通审稿人的三个权重由 `r1 = 0.6U1`、`r2 = (0.6-r1)U2`、`r3 = 0.6-r1-r2` 生成，再随机打乱并各加 `0.8`；因此三项权重之和为 `3`，每项约在 `0.8～1.4`。LLM 审稿人使用同样的拆分方式，但总额为 `2.4`、基础值为 `0.2`，三项权重之和仍为 `3`，每项约在 `0.2～2.6`。

基础拒稿线/接收线（接收线不含拒稿线）如下：

| 等级 | 新颖性 | 实验 | 普通 | LLM | 资深 | 心软 | 严格 | 恶意 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| A | 50/80 | 50/80 | 50/80 | 40/90 | 50/80 | 40/60 | 70/100 | 70/100 |
| B | 30/50 | 30/50 | 30/50 | 25/60 | 30/50 | 25/40 | 40/60 | 40/60 |
| C | 15/30 | 15/30 | 15/30 | 15/40 | 15/30 | 10/20 | 20/40 | 20/40 |

单项有效分低于拒稿线记 `-1`，达到拒稿线但低于接收线记 `0`，达到接收线记 `+1`。三位审稿人的总评 `≥+2` 必定录用，`≤-2` 必定退稿；总评为 `-1/0/+1` 时才进入 PC 概率判定。设投稿总分为 `S`，等级配置为 A `(基础率 0.50、基线 65、范围 30)`、B `(0.60、45、25)`、C `(0.80、28、20)`：

```text
x = (S - 基线) / 范围
m = (2 / (1 + exp(-x)) - 1) × 0.12
q = clamp(基础率 + 0.15 × 总评 + m, 0.08, 0.98)
总评 +1：P = 1 - 0.25 × (1-q)
总评  0：P = q
总评 -1：P = 0.25 × q
```

## 会议差异

同一等级使用同一套审稿人基础门槛，再由本次会议影响力相对该等级会议平均影响力调整：

```text
审稿标准倍率 = 本次会议影响力 / 该等级会议平均影响力
```

当前目录计算出的等级平均影响力为：A 类 `1.20`、B 类 `0.65`、C 类 `0.30`。因此同为 A 类会议，影响力 1.40 的会议门槛约为平均值的 `1.167` 倍，影响力 0.90 的会议约为 `0.750` 倍；该机制只读取静态会议目录，不依赖历史投稿数据库。

实际拒稿线和接收线分别为基础线乘以上述倍率后四舍五入；接收线至少比拒稿线高 1。

Spotlight、Oral、Best Paper Candidate 和 Best Paper 的分数门槛也使用同一倍率：

```text
实际档位门槛 = 基础档位门槛 × (本次会议影响力 / 该等级平均影响力)
```

投稿按钮上的参考分不是固定手填值：系统把三项分数视为均衡（`idea = 实验 = 写作`），枚举年度八类审稿人的三人组合，按各自门槛得到总评，再套用 PC 的边缘录用概率，逐分寻找首次达到 50% 录用率的总分。等级平均影响力下的参考分约为 C `20`、B `40`、A `70`，具体会议再按影响力比例调整。

## 结果与成长

- 审稿期结束后生成一个阻塞的“论文结果”事件，不立即改变论文或属性
- 玩家确认结果后，论文才正式发表或回到草稿
- 拒稿确认时，新颖性、实验、普通和资深审稿人的修改建议会分别累加到论文；普通审稿人的三项 `+2` 同时生效
- 每位心软审稿人确认结果时 `SAN +1`，每位恶意审稿人确认结果时 `SAN -2`；同一篇论文的多位审稿人可以累加

## 接收奖励递减

接收奖励会统计此前已发表的同级或更高等级论文，包括同月已经生成但尚未确认的录用结果：

- 每篇使本次 SAN 奖励减少 1，最低保留 1
- 每 2 篇使导师好感奖励减少 1，最低为 0
- 科研分不递减，继续体现论文数量对毕业和转博的价值

这样低水平会议仍可积累科研分，但无法在后期反复提供大量 SAN 和导师好感。

## 接收档位

- C/B 类保留 `Poster / Oral / Best Paper`，门槛分别为 C `35 / 50`、B `55 / 80`。
- A 类新增 `Spotlight / Best Paper Candidate`：Spotlight 分数门槛为 `80`，Oral 为 `90`，Best Paper Candidate 为 `110`，Best Paper 为 `125`。
- Spotlight 的奖励和引用倍率等同 Poster；Best Paper Candidate 的奖励和引用倍率等同 Best Paper，但抽中概率更低。
- A 类按 Best Paper、Best Paper Candidate、Oral、Spotlight 的顺序独立抽取；分数越高概率越高，未命中则降到下一个档位或 Poster。

当前 A 类抽取概率为：`P(Best Paper) = min(35%, 5% + (S-125)×2%)`，`P(Best Paper Candidate) = min(30%, 8% + (S-110)×2.5%)`，`P(Oral) = min(40%, 15% + (S-90)×3%)`，`P(Spotlight) = min(18%, 6% + (S-80)×1.5%)`；只有达到对应门槛才会抽取，前一档未命中才继续抽下一档。
