# 基础结局

当前已接入八种基础离校/未毕业结局，以及硕士、博士毕业。培养期按学位区分：硕士34个月（第三年6月），博士70个月（第六年6月）；毕业科研分要求分别为1分、7分，并且必须通过对应学位的毕业论文盲审。

| 结局 | 条件 |
| --- | --- |
| 不堪重负 | SAN低于0，且没有生效的应急保护 |
| 穷困潦倒 | 金币低于0 |
| 逐出师门 | 导师好感低于0 |
| 被孤立 | 社交能力低于0 |
| 用脑过度 | 科研能力低于0 |
| 实验室破产 | 科研经费低于0；等于0仍可继续 |
| 延毕 | 培养期结束，科研分尚未达标或毕业论文盲审未通过 |
| 主动退学 | 玩家在设置中确认结束学业 |
| 硕士毕业 | 第三年6月结束，仍为硕士，科研分≥1且硕士论文盲审通过 |
| 博士毕业 | 第六年6月结束，当前为博士，科研分≥7且博士论文盲审通过 |

0仍为安全值。天赋救援先结算；入学且选定导师后优先检查实验室经费，再检查应急装备、SAN、金币、导师好感、社交、科研。属性失败不必等到培养期结束才判定。

危险事件不只因余额不足而禁用。按钮“！”悬浮显示“会暴毙”，“？”悬浮显示“可能会暴毙”；缺少目标、前置未满足或次数用尽等限制仍禁用。危险事件不自动结算，玩家可手动确认后按结局条件判定。

毕业当年的6月可完整操作，进入该月、处理完最后一个到期事件或执行其他操作都不会自动触发毕业或延毕。玩家在硕二／硕三5月（内部第9月）处理转博决定；未转博时继续完成6月，处理完到期事件后，在该月点击“下一月”才判定毕业。成功转博后继续博士学业，不结算硕士毕业。毕业或延毕停留在第34／70个月，不额外推进到第35／71个月。毕业不会抢在本月论文结果和待办事件前结算，包括到期的非阻塞结果事件；超过培养期的未来事项不再拖住结局。分数提前达标也不会提前毕业。

毕业论文在毕业学年准备，4月起进入盲审流程。科研分达标才能送审，硕士3位、博士5位专家全部给出A/B才通过，全部为A则记录优秀学位论文。工作offer独立于毕业门槛，未获得offer不妨碍毕业。

同学也在6月结束时先判定转博，再判定毕业或退学：第二／三年硕士科研分达到2／3先转博；第三年仍为硕士需1分，第六年博士需7分。未达标直接退学，不设延毕，移出人际栏；已有论文责任保留。

结局出现时切到事件时间轴的“结局”节点，展示角色与在校时长、大论文、代表作、科研统计、最终属性、导师、offer、同学、恋人和经历计数；失败保留触发事件。结局也播报本局新达成成就，并预览经验。主界面仍可切换栏目和查看历史，普通游戏操作停止。

只有点击“结算并返回”才确认本局，发放成就与经验奖励、提交最终分支统计并清除该角色旧存档，随后返回开始页，不自动开新局。设置里的“返回开始页面”保留本局；“我要回溯”打开读档，读取后删掉后续月份与分支进度。打开调试面板或回放校验失败的局不发奖励，也不继续上传统计。
