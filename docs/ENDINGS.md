# 基础结局

本轮先接入旧版的六种基础离校/未毕业结局，以及普通硕士、博士毕业。保留新版既定的68个月培养期和导师毕业分数要求，不迁回旧版培养年限。

| 结局 | 条件 |
| --- | --- |
| 不堪重负 | SAN低于0，且没有生效的应急保护 |
| 穷困潦倒 | 金币低于0 |
| 逐出师门 | 导师好感低于0 |
| 被孤立 | 社交能力低于0 |
| 延毕 | 培养期结束，科研分尚未达标 |
| 主动退学 | 玩家在设置中确认结束学业 |
| 硕士毕业 | 培养期结束，当前为硕士，科研分达到硕士要求 |
| 博士毕业 | 培养期结束，当前为博士，科研分达到博士要求 |

0仍为安全值。失败沿用新版现有判定优先级：SAN、金币、导师好感、社交；科研能力不作为失败条件。应急装备先按自身规则生效。

毕业不会抢在本月论文结果和待办事件前结算；超过培养期的未来事项不再拖住结局。分数提前达标也不会提前毕业。大论文和求职尚未接入毕业门槛。

结局出现时自动切到事件栏时间轴末尾的“结局”节点，该页只展示单幕结局卡片，不混排当月日志。卡片包含情境叙事、触发条件、角色与在校时长、发表成果和最终属性，四种属性失败额外保留最后发生的事情，方便整体截图。关闭卡片后停留在结局节点，显示一条可点击的结局日志，点击即可重新打开。普通月份不再展示重复的系统结局通知，仍保留导致结局的事件记录。保留游戏主界面，玩家可切换栏目、翻阅成果和历史事件；下一月及其他游戏操作停用，重开和返回开始页可以开始下一轮。

暂不制作优秀毕业、学术职业、特殊角色等高级结局，不接入生涯回顾、成就结算、跨局解锁或持久化记录。
